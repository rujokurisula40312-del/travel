# Стартовые коды ботов для турагентства

Шаблоны для мастермайнда «Telegram-бот за 7 дней».

## Боты

| Файл | Что делает |
|------|-----------|
| `1_lead_magnet_bot.py` | Воронка: выдаёт лид-магнит за подписку на канал |
| `2_faq_bot.py` | FAQ: отвечает на типовые вопросы туристов кнопками |
| `3_database_bot.py` | База данных: добавляет и ищет записи через Telegram |
| `4_calendar_bot.py` | Расписание: клиент выбирает слот → запись в Google Calendar |
| `5_antispam_bot.py` | Антиспам: банит по ключевым словам, уведомляет admin |
| `6_document_bot.py` | Документы: генерирует PDF заявление на возврат по номеру заявки |

## Установка

```bash
pip install -r requirements.txt
```

Каждый файл — самостоятельный бот. Открой нужный, замени значения в верхней части файла (токен, ID, реквизиты) и запусти:

```bash
python 1_lead_magnet_bot.py
```

## Как получить токен

1. Открой @BotFather в Telegram
2. Напиши `/newbot`
3. Введи имя и username бота
4. Скопируй токен
