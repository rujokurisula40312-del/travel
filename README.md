# Travel Bot Pro

Telegram-бот для турагентств: ИИ-консультант + квалификация лидов + выдача программ туров + лист ожидания. Работает 24/7, разгружает менеджеров от типовых вопросов, передаёт заявки в Google-таблицу и шлёт уведомления менеджеру в Telegram.

## Как это работает

```
        Турист (Telegram)
              │
              ▼
    ┌──────────────────────┐
    │   Travel Bot Pro     │
    │ ┌──────────────────┐ │
    │ │  Меню + кнопки   │ │  ──▶ PDF из Google Drive
    │ │  ИИ-консультант  │ │  ──▶ Anthropic Claude (без ПД!)
    │ │  Сценарий записи │ │  ──▶ Google Sheets (с ПД)
    │ └──────────────────┘ │
    └──────────┬───────────┘
               │
               ▼
       Менеджер (Telegram)
       получает уведомление
       и связывается с туристом
```

**Что бот умеет:**
- Отвечать на свободные вопросы про туры, визы, климат, безопасность.
- Выдавать PDF программ туров по кнопке.
- Собирать заявки: ФИО, телефон, email, кол-во человек — всё с согласием по ФЗ-152.
- Писать заявки в Google-таблицу клиента.
- Уведомлять менеджеров о новых заявках в Telegram.
- Удалять данные пользователя по команде `/delete_me`.
- Поддерживать **несколько турагентств** в одном инстансе (SaaS-режим).

**Чего бот не делает (намеренно):**
- Не передаёт ПД (ФИО, телефон, email) в Anthropic Claude.
- Не «занимает» места — место фиксируется только после предоплаты, которую принимает менеджер.

## Конфиденциальность и ФЗ-152

Бот спроектирован с учётом требований Федерального закона № 152-ФЗ «О персональных данных»:

- **Согласие до сбора:** FSM не пускает в шаги сбора ПД без явного согласия пользователя.
- **Изоляция от ИИ:** в Anthropic Claude уходит только обезличенный контекст (`AnonymousContext` — отдельный тип данных, ПД туда невозможно положить случайно).
- **Маскирование в логах:** телефоны и email фильтруются `PIIMaskFilter` перед записью в логи.
- **Право на удаление:** команда `/delete_me` удаляет все строки пользователя из всех листов туров и пишет факт в журнал `_audit`.
- **Версионирование согласия:** при изменении политики все ранее данные согласия становятся неактуальными — пользователь даёт согласие заново.

Подробно про юридические требования — в [`docs/templates/rkn-guide.md`](docs/templates/rkn-guide.md) и [`docs/templates/privacy-policy.md`](docs/templates/privacy-policy.md).

## Команды бота

| Команда | Кому | Что делает |
|---|---|---|
| `/start` | туристам | Приветствие + меню |
| `/menu` | туристам | Главное меню |
| `/cancel` | туристам | Отменить текущий шаг |
| `/manager` | туристам | Связаться с менеджером |
| `/delete_me` | туристам | Удалить мои данные |
| `/help` | туристам | Список команд |
| `/reload` | владельцу | Сбросить кеш (после правки таблицы) |
