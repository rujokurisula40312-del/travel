# Сценарии диалогов и FSM

> Здесь — конкретные шаги общения бота с туристом, состояния FSM (`aiogram.fsm`) и примеры реплик. Это то, по чему я (или разработчик) кодирую `routers/` и `usecases/`.

---

## 1. Карта FSM

```
                    ┌──────────────────┐
                    │      idle        │  ◀── /start, любое первое сообщение
                    └──────┬───────┬───┘
              кнопка       │       │   свободный текст
                           ▼       ▼
        ┌────────────────────┐    ┌─────────────────────┐
        │ menu (без FSM)     │    │ ai_chat             │
        │ программа / чек-   │    │ (ИИ-консультант)    │
        │ лист / оплата      │    └──────────┬──────────┘
        └────────┬───────────┘               │
                 │   "хочу записаться"       │
                 └──────────┬────────────────┘
                            ▼
                   ┌─────────────────┐
                   │  Booking FSM    │
                   ├─────────────────┤
                   │ waiting_country │
                   │ waiting_dates   │
                   │ waiting_pax     │
                   │ waiting_budget  │
                   │ waiting_consent │  ◀── ФЗ-152
                   │ waiting_name    │
                   │ waiting_phone   │
                   │ waiting_email   │
                   │ confirming      │
                   └────────┬────────┘
                            │
                seats > 0  ─┴─ seats == 0
                    │           │
                    ▼           ▼
              ┌──────────┐  ┌──────────────┐
              │  booked  │  │ Waitlist FSM │
              └────┬─────┘  └──────┬───────┘
                   │               │
                   └──────┬────────┘
                          ▼
                  notify manager(s)
                          │
                          ▼
                       idle
```

В любой момент: `/cancel` → `idle`. Команда `/menu` всегда доступна.

## 2. Сценарий A — «дай PDF по Китаю»

**Самый частый случай.** Турист хочет программу — получает PDF.

```
Турист: /start
Бот:    Привет! Я бот турагентства «Светлана Тур».
        Помогу подобрать тур, отвечу на вопросы и запишу на поездку.

        Что вас интересует?
        [📋 Все туры]  [🌏 Программы по странам]
        [✅ Чек-лист]  [💳 Оплата]
        [👤 Менеджер]

Турист: Программы по странам
Бот:    Выберите направление:
        [🇨🇳 Китай]  [🇸🇨 Сейшелы]  [🇿🇦 ЮАР]  [🇹🇭 Таиланд]  [...]

Турист: Китай
Бот:    Вот программа авторского тура «Пекин — Сиань — Шанхай»,
        15–25 апреля, от 185 000 ₽.
        [PDF: cn-2025-04-pekin.pdf]

        Хотите узнать подробности или записаться?
        [📝 Записаться]  [❓ Спросить ещё]  [⬅️ Назад]
```

**Технически:** `routers/menu.py` → `usecases/send_program.send(country_code=CN)` → читает первый активный тур этой страны → `services/drive.get_pdf(file_id)` → `bot.send_document`.

Если по стране несколько туров — бот сначала показывает список:

```
Бот:    По Китаю у нас есть 3 программы:
        [Пекин 15–25.04 — 185 000 ₽]
        [Шанхай 10–18.09 — 165 000 ₽]
        [Юньнань 5–14.10 — 220 000 ₽]
```

## 3. Сценарий B — «хочу в Китай» (свободный текст)

```
Турист: хочу в Китай в апреле на двоих
Бот:    [через ИИ + поиск туров] У нас есть как раз подходящий тур:
        авторская поездка по Пекину 15–25 апреля, ещё есть 7 мест.
        Цена — 185 000 ₽ с человека.

        [📄 Программа]  [📝 Записаться]  [❓ Узнать про визу]
```

**Технически:**
1. `routers/ai_chat.py` ловит свободный текст.
2. Use-case `find_tour` (LLM-классификатор: `country` + `month` + `pax`) → ищет в `tours` Sheets.
3. Если нашёл — показывает карточку тура. Если нет — `usecases/ai_consult` (ИИ-ответ + признание «у нас этого направления нет»).

> Альтернатива классификатору — отдать всё Claude и попросить вернуть JSON с интентом + параметрами. Это проще, но медленнее. Решить в [`open-questions.md`](open-questions.md).

## 4. Сценарий C — вопрос «нужна ли виза»

```
Турист: А виза в Сейшелы нужна?
Бот:    [через ИИ + Notion] Гражданам РФ виза в Сейшелы не нужна для
        туристических поездок до 30 дней. На границе оформляется
        бесплатное разрешение на въезд (Visitor's Permit) — нужно
        предъявить обратный билет, бронь отеля и подтверждение
        средств.

        Хотите программу нашего тура на Сейшелы?
        [📄 Программа]  [📝 Записаться]  [❓ Ещё вопрос]
```

**Технически:**
1. ИИ-консультант распознаёт страну в вопросе.
2. `services/notion.get_country_kb('SC')` → возвращает markdown.
3. `claude.answer(AnonymousContext(country_kb=..., user_question=...))` — ответ.
4. К ответу всегда подклеиваются подходящие CTA-кнопки.

## 5. Сценарий D — запись на тур (подробный)

Самый ответственный — потому что ПД и места.

```
Турист: [нажимает 📝 Записаться]
Бот:    Отлично! Записываю на «Авторский тур по Пекину» (15–25 апреля).
        
        Перед тем как продолжить, мне нужно ваше согласие на обработку
        персональных данных. Вы передадите имя, телефон и email — мы
        используем их только для оформления поездки.
        
        📄 Политика: https://...
        
        [✅ Согласен]  [❌ Отмена]
```

→ FSM: `idle` → `Booking.waiting_consent`

```
Турист: ✅ Согласен
Бот:    Спасибо! Как вас зовут? (ФИО полностью)
```

→ FSM: `Booking.waiting_consent` → `Booking.waiting_name`. В стейте: `consent_at=now()`, `consent_text_version="v1"`.

```
Турист: Иванов Иван Иванович
Бот:    Приятно познакомиться, Иван!
        Оставьте, пожалуйста, ваш телефон. Можно нажать на кнопку
        ниже, чтобы поделиться номером Telegram.
        [📱 Поделиться номером]
```

→ FSM: `waiting_name` → `waiting_phone`. Используем `KeyboardButton(request_contact=True)`.

```
Турист: [нажимает кнопку, бот получает contact]
Бот:    Записал: +79161234567.
        Email для подтверждения брони?
```

→ FSM: `waiting_phone` → `waiting_email`. Валидация: regex.

```
Турист: ivan@example.com
Бот:    Сколько человек поедет?
        [1]  [2]  [3]  [4+]
```

→ FSM: `waiting_email` → `waiting_pax`.

```
Турист: 2
Бот:    Проверяю наличие мест...
        
        ✅ Готово! Записал вас на тур.
        
        📋 Заявка №f47ac10b
        Тур: Авторский тур по Пекину
        Даты: 15–25 апреля 2025
        Человек: 2
        
        Менеджер свяжется с вами в течение 24 часов для оплаты и
        деталей. Если что-то срочно — нажмите [👤 Менеджер].
```

→ FSM: `waiting_pax` → `confirming` → попытка `book_seat()`:
- Lock на `tour_id`
- Чтение `available_seats`
- Если ≥ `pax`: запись лида + декремент → `idle`
- Если < `pax`: переход в `Waitlist.waiting_consent` (согласие уже есть, можно сразу в `waiting_contacts` — но контакты тоже уже есть, сразу запись).

Параллельно: `notifier.notify_new_lead()` → менеджеры получают уведомление.

## 6. Сценарий E — лист ожидания

```
Бот:    К сожалению, на этот тур уже все 10 мест заняты 😔
        
        Хотите я добавлю вас в лист ожидания? Если кто-то откажется
        от поездки, менеджер сразу свяжется с вами.
        
        [📋 В лист ожидания]  [🌏 Другие туры]  [👤 Менеджер]
```

Если согласие уже было — сразу пишем в `waitlist`. Если нет — отдельный сценарий с согласием.

## 7. Сценарий F — страны нет в базе

```
Турист: А есть туры в Антарктиду?
Бот:    Антарктиды у нас, к сожалению, пока нет 😔
        
        У нас есть похожие по духу направления — экзотика и редкие
        маршруты:
        
        [🇿🇦 ЮАР]  [🇸🇨 Сейшелы]
        
        Или хотите, я передам ваш интерес менеджеру? Возможно, мы
        сможем подобрать что-то под запрос.
        
        [👤 Менеджер]  [⬅️ Другие туры]
```

Логика: `find_tour` не нашёл → `ai_consult` отвечает с признанием отсутствия + предлагает альтернативы (страны с тэгом `exotic` из Notion) или менеджера.

## 8. Сценарий G — оффтоп / небезопасные темы

```
Турист: расскажи анекдот
Бот:    Я помогаю с турами и поездками 🙂 По другим темам не подскажу.
        Хотите узнать про наши направления? [🌏 Все туры]
```

Реализация: системный промпт + классификатор интента (in-scope/out-of-scope). При out-of-scope — короткий вежливый отказ.

## 9. Сценарий H — перевод на менеджера

**MVP (эстафета):**

```
Турист: [нажимает 👤 Менеджер]
Бот:    Передаю вас Светлане. Она напишет вам в течение часа в
        рабочее время (10:00–20:00 МСК).
        
        Пока что можете оставить вопрос — я передам.

Турист: спросите можно ли с детьми
Бот:    Передал! Светлана ответит как только сможет.
        
        [⬅️ В меню]
```

Менеджер получает в Telegram:

```
🟡 Запрос на перевод

Турист: @ivan_petrov (telegram_id 123456)

[Открыть чат] tg://user?id=123456
```

## 10. Сценарий I — `/delete_me`

```
Турист: /delete_me
Бот:    Вы уверены, что хотите удалить все ваши данные? Эта операция
        необратима — мы удалим ФИО, телефон, email и историю записей.
        
        [✅ Да, удалить]  [❌ Отмена]

Турист: ✅ Да, удалить
Бот:    Готово. Все ваши данные удалены из нашей базы.
        Если захотите снова — просто напишите /start.
```

Технически: `usecases/delete_me.delete(telegram_id)` → находит все строки в `leads` и `waitlist` по `telegram_id` → удаляет → пишет факт удаления в `audit`.

## 11. Команды

| Команда | Что делает |
|---|---|
| `/start` | Приветствие + меню |
| `/menu` | Показать главное меню |
| `/cancel` | Отменить текущий сценарий, вернуться в `idle` |
| `/manager` | Перевод на менеджера |
| `/delete_me` | Удалить ПД |
| `/help` | Список команд |
| `/reload` | (только для `owner_telegram_id`) сбросить кеши |

## 12. Тон ИИ

Шаблон системного промпта (`prompts/system_prompt.j2`):

```jinja
Ты — ИИ-консультант турагентства "{{ agency_name }}". Тебя зовут {{ bot_name }}.

ТОН: {{ tone }}.
{% if tone == "friendly" -%}
Общайся тепло, простыми словами, на «вы». Можно использовать смайлики (умеренно).
{%- elif tone == "formal" -%}
Общайся вежливо и сдержанно, на «вы». Без смайликов.
{%- endif %}

ТЫ МОЖЕШЬ:
- Рассказывать про туры из списка ниже.
- Отвечать на вопросы про визы, климат, что брать с собой, безопасность.
- Помогать определиться с направлением.

ТЫ НЕ МОЖЕШЬ:
- Называть конкретные цены, даты или количество мест — для этого есть кнопка «Программа».
- Обещать ничего, что не указано в базе знаний.
- Отвечать на вопросы вне темы туризма.
- Запрашивать у пользователя ФИО, телефон или email — это делает другой блок.

АКТИВНЫЕ НАПРАВЛЕНИЯ:
{% for c in countries -%}
- {{ c.name }} ({{ c.code }})
{% endfor %}

КОНТЕКСТ ПО СТРАНЕ:
{{ country_kb }}

Если не знаешь ответ — честно скажи и предложи: «Хотите, я передам вопрос менеджеру?»
```
